# RakthaSethu Frontend

React + TypeScript + Vite + Tailwind frontend shell for RakthaSethu.

## Phase 1 foundation
- Role-aware route skeleton (`/login`, `/register`, `/dashboard`).
- Reusable layout and card components.
- Healthcare-themed responsive baseline UI.
- Prepared structure for upcoming modules and protected routes.

## Run locally
```bash
npm install
npm run dev
```
